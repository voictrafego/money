<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → Traefik → app/www | Ingress único com TLS; gate intercepta app antes de rotear |
| Browser → WS /_stcore/stream | Handshake autenticado uma vez; frames confiam na conexão |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-12 | Info Disclosure | TLS/cert | mitigate | Validar cert válido (não default) em www/app; DNS cinza garante ACME; HSTS ativo |
| T-03-13 | Spoofing | acesso direto ao app | mitigate | Verificado ao vivo: app sem sessão → 302 login; money sem porta pública |
| T-03-14 | Repudiation/DoS | app em loop de auth (WS) | mitigate | Validação de WS ao vivo; fallback config.toml aplicável se o handshake XSRF/CORS recusar |
| T-03-15 | Availability | downtime no cutover | mitigate | Deploy do lazari validado ANTES de remover o money antigo (Pitfall 6); sem --remove-orphans (n8n) |
| T-03-16 | Data loss | perda do Postgres | mitigate | Cron de backup diário + retenção 7d antes de tráfego pago real |
</threat_model>
