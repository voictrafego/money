## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config.yaml → setup.py | `cfg` é config versionado/confiável; lido como dict, sem eval. Único "input" de tuning. |
| SinaisTecnicos (interno) → setup.py | Contrato já validado na borda de ingest (Fases 12–13). `setup.py` não recebe input de usuário/rede novo. |
