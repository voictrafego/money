"Subavaliada"/"Cara" directly, never touching `core.arquetipo`, `core.motores`, `report.analisar_acao`,
or the Phase-1 freio (`alvo_regressao_confiavel`). Live, same run/tickers/data:

```
Streamlit Ranking tab:          Analisar tab (report.analisar_acao):
ITUB4 → "Cara" (alvo R$31.21)   ITUB4 → motor=rim, "DDM conservador demais para este
                                        perfil — ver motor primário" (SAN-01 fires)
VALE3 → "Cara" (alvo R$63.03)   VALE3 → motor=normalizado, same SAN-01 protection
```

This is the exact failure mode ("compounders de qualidade carimbados como evitar/cara") the whole
milestone was built to eliminate, reproduced one tab away from the fixed surface. The CLI equivalent
(`cmd_rank`) already applies the freio — so the gap is specific to the Streamlit Ranking surface.
